# Enterprise Project Management Dashboard

A modern and responsive project management dashboard built with React and Vite. The application provides an interactive workspace for managing projects, tasks, team members, analytics, notifications, and activities through a clean enterprise-style user interface.

## Features

- Interactive Dashboard Overview
- Project Management
- Add, Edit, and Delete Projects
- Task Management
- Task Status Tracking
- Team Member Management
- Dashboard Analytics
- Project Progress Tracking
- Weekly Activity Charts
- Team Performance Overview
- Upcoming Deadlines
- Recent Activity Timeline
- Notification System
- Global Search
- Dark and Light Theme
- Local Storage Data Persistence
- Responsive Layout
- Custom 404 Page
- Modern Enterprise UI

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM
- Context API
- Recharts
- Lucide React
- React Circular Progressbar
- React Hot Toast
- Local Storage

## Core Modules

### Dashboard

Provides an overview of projects, completed tasks, pending tasks, team members, project progress, deadlines, recent activities, and team performance.

### Projects

Allows users to manage project information including project name, client, status, priority, progress, due date, and assigned team members.

### Tasks

Provides task management functionality with task creation, editing, deletion, status updates, priority management, and deadline tracking.

### Team

Allows users to manage team members and view team-related information and performance.

### Analytics

Displays visual insights and activity data using interactive charts.

### Notifications and Activity

Automatically tracks important application events such as project creation, task updates, task status changes, and team member activities.

### Theme Management

Supports light and dark themes for an improved user experience.
